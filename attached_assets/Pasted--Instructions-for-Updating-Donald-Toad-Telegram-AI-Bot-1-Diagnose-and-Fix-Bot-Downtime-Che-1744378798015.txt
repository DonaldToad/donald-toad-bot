## 3. Add and Tag Trivia and Guessing Games
- Trigger by user message: `Play Trivia`
- Use `update.effective_user.mention_html()` to tag the winner

```python
def play_trivia(update, context):
    question = "Which crypto has the largest market cap?"
    answer = "bitcoin"
    context.bot_data['trivia'] = {'question': question, 'answer': answer, 'answered': False}
    update.message.reply_text(question)

def handle_response(update, context):
    user_answer = update.message.text.lower()
    trivia = context.bot_data.get('trivia', {})
    if trivia and not trivia.get('answered'):
        if user_answer in trivia['answer']:
            context.bot_data['trivia']['answered'] = True
            update.message.reply_text(f"{update.effective_user.mention_html()} got it right! 🐸", parse_mode='HTML')
```
